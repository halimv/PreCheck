Each round

  1. Verifier checks the plan against safety rules
  2. Compiler turns it into PyLabRobot code
  3. Simulator runs that code on PLR's ChatterBox backend

On a failure, the model proposes edits to the plan. The harness accepts them only if they fix the failing step without changing how much liquid is moved. A passing plan can then be replayed in PyLabRobot's own visualizer.
