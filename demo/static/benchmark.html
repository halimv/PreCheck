Reading the spread

At temperature 0 the model gives the same answer every time, so one run per scene is all you get. At a higher temperature each repeat can go differently; a cell shows how many repeats healed and one button per repeat.

Per repeat: healed scenes in each pass over all scenes, so you can see how much one pass varies.

95% interval: the scenes are resampled many times and the heal rate recomputed. It shows how much the rate depends on which scenes were picked. It says nothing about protocols that aren't in the benchmark.

Score (−1 to 5)

  1. C1 Protocol starts correctly
  2. C2 Model names the fault
  3. C3 Model states the correct fix
  4. C4 The correct fix is applied
  5. C5 Final concentrations within 1%

−1 if the protocol still fails when the budget runs out. Diagnosis = C2 + C3, execution = C4 + C5. C2 and C3 are keyword checks on the model's reasoning, so spot-check them in the rounds.

Conditions

  1. B0 No repair: the floor
  2. B1 Applies the diagnostic's own suggested fix, no model
  3. Lab-concept Model sees the translated diagnostic
  4. Raw Model sees only the PyLabRobot exception
